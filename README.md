README.md# NOVA — Responsive Landing Page

A modern, futuristic and fully responsive landing page built as part of the Elevate Labs Web Development Internship — Task 1.

## 🚀 About the Project

NOVA is a fictional futuristic digital workspace designed to help creators turn ideas into powerful digital experiences.

The landing page focuses on a clean, premium and modern user interface while demonstrating fundamental web development concepts using HTML5 and CSS3.

## ✨ Features

- Responsive navigation bar
- Modern hero section
- Call-to-action buttons
- Interactive-looking dashboard UI
- Feature section
- Final CTA section
- Social links in footer
- Hover effects
- Responsive design for desktop, tablet and mobile
- CSS Flexbox and Grid layouts
- CSS Media Queries

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Responsive Web Design
